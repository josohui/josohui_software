# 확장 틱택토

소프트웨어 시스템 설계 체크포인트 4용 Java Swing 게임, Beta 1.0.
화면, 게임 규칙, 플레이어 정보를 별도의 클래스로 구성했습니다.

## 실행 — 빌드할 필요 없음

1. GitHub에서 Code → Download ZIP을 선택합니다.
2. ZIP 전체를 압축 해제합니다.
3. 압축을 푼 폴더의 `run.bat`를 더블클릭합니다. Windows에서 확장자가 숨겨져 있으면 `run`으로 표시됩니다.

실행 JAR이 `dist/ssd_ip_cp4_2026f_252482_app.jar`에 포함되어 있습니다.
Java 17 이상이 필요하며 JDK, PowerShell 명령 입력, 직접 컴파일은 필요하지 않습니다.
`run.bat`만 따로 옮기지 말고 `dist` 폴더와 함께 두세요.
외부 라이브러리와 네트워크 연결은 필요하지 않습니다.

### 소스를 수정한 경우에만 다시 빌드

JDK 17 이상에서 `powershell -ExecutionPolicy Bypass -File build.ps1`을 실행합니다.
이 명령은 테스트, 실행 JAR 생성, Javadoc 생성을 수행합니다.
일반적인 게임 실행에는 이 과정이 필요하지 않습니다.

## 규칙

- 한 기기에서 O와 X 두 명이 번갈아 놓습니다. O가 먼저 시작합니다.
- 빈 이름은 플레이어 1/2를 사용합니다. 같은 이름도 O/X로 구분됩니다.
- 한 차례는 30초입니다. 7초 이하에서는 경고하고 시간 초과 시 수 없이 차례를 넘깁니다.
- 게임판은 3×3 → 6×6 → 10×10 → 17×17로 확장됩니다.
- 같은 표시 3 → 4 → 5 → 6개 이상 연속이면 승리합니다. 가로, 세로, 양쪽 대각선을 검사합니다.
- 승자 없이 판이 가득 차면 기존 표시를 보존하며 다음 크기로 확장합니다.
- 확장 시 위/왼쪽과 아래/오른쪽에 각각 1/2칸, 2/2칸, 3/4칸을 추가합니다.
- 17×17에서도 승자 없이 가득 차면 최종 무승부입니다. 마지막 수의 승리가 무승부보다 우선합니다.
- 새 경기는 이름과 기록을 유지합니다. 진행 중에 재시작하면 중단된 경기는 기록하지 않습니다.
- 확인 대화상자에서는 시간을 멈추고, 취소하면 남은 시간부터 이어갑니다.
- 종료하면 기록은 사라집니다. 온라인 대전과 파일 저장은 제공하지 않습니다.

## 구조

- `Main`: 실행과 기본 글꼴 설정
- `GameFrame`: JFrame 기반 화면과 입력/타이머 이벤트 처리
- `GameModel`: 게임판, 차례, 확장, 승리와 시간 판정
- `Player`: 이름, O/X 표시, 누적 승패 기록
- `GameModelTest`: 가상 시계와 테스트 상태를 이용한 규칙 회귀 검사
